## 3. 方法路线

1. **EDA 与假日效应**：2025 年法定节假日与调休（国务院办公厅通知：元旦 1/1；春节 1/28–2/4，调休 1/26、2/8；清明 4/4–4/6；劳动节 5/1–5/5，调休 4/27；端午 5/31–6/2；中秋国庆 10/1–10/8，调休 9/28、10/11）。用带星期、月份、节假日哑变量的回归（HC 稳健标准误）或 STL + 反事实估计假日效应；注册数对各单元消费的分布滞后/adstock 回归给出边际注册成本。
2. **分类**：效益指数 = 标准化后的加权组合（权重来自熵权或 PCA，并做等权稳健性对照）；阈值用中位数 / 二分类 K-means（对数尺度）/ Jenks 三种方法，报告一致率；无效词 = 零消费且零效益。
3. **分配优化**：每个关键词响应函数为凹函数（如 clicks = a·(1−exp(−spend/b)) 或幂函数，参数由年度 CPC 与单元日曲线拟合）；单元预算约束；目标最大化期望注册（或效益指数）；分离凹规划用 KKT / 贪心边际收益（证明最优）或 cvxpy 求解；样本外对照：与 2025 同日实际结果比较，报告提升幅度与置信区间（bootstrap）。
4. **预测与不确定性**：单元级日序列（消费、展现、点击、CPC、上方位占比）用带周季节与趋势的模型（ETS/SARIMAX 或梯度提升带滞后特征），滚动回测（2025 年后段）报告 MAE、MAPE、pinball loss 与 80% 区间覆盖率；2026-09-11…17（周五至周四，无法定节假日）给出点预测与区间；分配采用样本平均近似（SAA）或稳健优化，附 CVaR 超支约束。
5. **验证**：分类稳健性、回测指标、分配对照、灵敏度（效益权重、响应函数形状、预算 ±20%）。

## 4. 论文必须包含

数据说明与质量、假日效应检验结果（含 p 值或区间）、分类结果概要表与散点图（成本–效益象限）、分配模型与优越性证明、预测区间图、局限（数据粒度：关键词只有年度汇总；注册归因间接）。
