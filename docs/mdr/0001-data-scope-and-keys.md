# MDR-0001 数据范围、关键词主键与无效词的判定

日期：2026-09-12 · 状态：已采纳 · 关联问题：全部

## 问题
题目称"5 个方案、12 个推广单元、6000 多个关键词、2025 年投入约 142 余万元"。附件 1 的 Sheet3 只有 2227 行关键词记录（1884 个不同的关键词 ID，ID 取值范围 2–6662），其中 890 行全年零消费零点击；Sheet1 有 2627 条单元-日记录，消费合计 1,425,949.79 元，与题述一致；Sheet3 的分单元消费与点击合计与 Sheet1 完全对账。343 行的关键词 ID 在多个推广单元中重复出现（290 个 ID 被 2–4 个单元共用）。两条记录消费为 0、点击为 0 但浏览量为 1。

## 备选方案
1. 以 `关键词` ID 作为主键；重复 ID 合并——会把不同单元中的同一词混为一条，与 result2 模板（方案ID、推广单元、序号）不符。
2. 以 `(方案ID, 推广单元ID, 序号)` 作为主键，把不同单元中的同一 ID 视为不同投放对象（"关联关系"在问题三中显式处理）。
3. 无效词按"零消费且零点击且零浏览"判定——两条"零消费、零点击、浏览 1"的记录会落入潜力词。
4. 无效词按"零消费且零点击"判定——未购买任何点击的词不可能通过广告产生效益，浏览量为 1 视为统计噪声。

## 决策与理由
采用 2 与 4。`序号` 是模板要求的标识；"6000 多个关键词"理解为账户内全部关键词，附件只提供了其中 2227 条有统计记录的子集，论文数据说明中如实指出。无效词 = 零消费 ∧ 零点击（890 个），与题述"无成本、无效益"一致。

## 对结果的影响与验证
无效词数量由 888 变为 890；分类校验器（`verify_classification`）以同一规则独立复核。重复 ID 的处理见 MDR-0006。
