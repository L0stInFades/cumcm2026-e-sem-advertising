# MDR-0005 关键词响应函数、弹性估计与点击价值（问题三、四）

日期：2026-09-12 · 状态：已采纳 · 关联问题：问题 3、4

## 问题
附件只有关键词的年度汇总（消费、点击、浏览、跳出率、时长），没有关键词的日序列或出价-点击曲线；分配模型需要"投入 → 点击"的凹响应函数。

## 备选方案
1. 线性响应（点击 = 投入 / CPC）——最优解为把预算全压在最便宜的词上，与"边际效益递减"事实不符。
2. 幂函数（Cobb–Douglas）$q_i(x)=c_i (x/s_i)^{\gamma_u}$：$s_i,c_i$ 为该词在单元活跃天数上的日均消费与日均点击（曲线过历史工作点），形状参数 $\gamma_u$ 由单元日序列回归 $\log \text{clicks}=\text{const}+\gamma\log\text{spend}+\text{weekday}$ 估计。
3. 指数饱和 $q_i(x)=a_i(1-e^{-x/b_i})$：需两参数，用单元日序列拟合的残差平方和在 11/12 个单元上大于幂函数。

## 决策与理由
采用 2。单元级估计 $\hat\gamma_u\in[0.65,0.93]$，合并估计（单元固定效应）$0.836\ (\text{SE }0.011)$，说明边际收益递减；估计落在 $[0.3,0.95]$ 之外或天数不足 60 的单元（4 词的品牌型单元 8878077181：$\hat\gamma=1.33$；2526158329：$n=56$）使用合并弹性。每次点击的价值 $\rho_i = r_u\,\kappa_i$，$r_u$ 为单元注册率（MDR-0003），$\kappa_i=(1-b_i)/(1-\bar b_u)$ 为跳出率质量因子（截断到 $[0.25,2.5]$，无访问记录的词取 1）；浏览量 = 点击 × 该词历史每次点击浏览页数（无记录时用单元均值）。72 个"有点击但浏览量为 0 且跳出率为 0"的词视为访问追踪缺失，两项均回退到单元均值。

## 对结果的影响与验证
"按历史比例分配"在幂函数下的预测点击与实际点击对照（MAPE）作为响应模型校准证据；弹性 ±10%、上限倍数变化的灵敏度表见 `sensitivity`；$\gamma$ 的抽样不确定性用参数自助法传播到问题三的提升区间。
