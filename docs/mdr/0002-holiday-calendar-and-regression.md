# MDR-0002 假日效应的定义与检验方法（问题一）

日期：2026-09-12 · 状态：已采纳 · 关联问题：问题 1

## 问题
题目要求"分析投放效益与投放时间的变化规律和假日效应"。需要确定：哪些日期算节假日，用什么统计模型量化并检验效应。

## 备选方案
1. 仅按周末/工作日划分——忽略法定节假日与调休。
2. 按国务院办公厅 2025 年节假日安排：元旦 1/1；春节 1/28–2/4；清明 4/4–4/6；劳动节 5/1–5/5；端午 5/31–6/2；国庆中秋 10/1–10/8；调休上班日 1/26、2/8、4/27、9/28、10/11。
3. STL 分解后比较假日残差——参数选择多、结果不便检验。
4. 带日历哑变量的对数线性回归 + HC3 稳健标准误 + Mann–Whitney 非参数检验作为稳健性对照。

## 决策与理由
采用 2 + 4。模型：$\log y_t = \alpha + \sum_w \beta_w \mathbb{1}[\text{weekday}_t=w] + \sum_m \mu_m \mathbb{1}[\text{month}_t=m] + \delta_h H_t + \delta_a A_t + \delta_{pre} P_t + \delta_{post} Q_t + \epsilon_t$，基准为周三与 1 月；$y$ 取日注册数、消费额、点击量、展现量（对数）以及 CPC、CTR、上方位占比（水平）。效应以 $100(e^{\delta}-1)\%$ 报告并给出 95% 置信区间与 $p$ 值。另外估计"控制当日消费额（log）后的注册假日效应"，以区分需求侧假日效应与公司主动减投的影响。

## 对结果的影响与验证
注册数假日效应约 −74%（$p<10^{-20}$），消费额 −77%，CPC 与 CTR 无显著假日效应；Mann–Whitney 检验（假日 vs 普通工作日中位数）结论一致。周一与周日的显著负效应反映公司在这些日子主动减投。结果进入论文问题一与"模型检验"。
