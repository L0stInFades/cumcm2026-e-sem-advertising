# MDR-0010 论文呈现约定：归因注册的口径、最优性证书的报告方式与分配图

日期：2026-09-12 · 状态：已采纳 · 关联问题：问题 1、3、4

## 问题
撰写论文时发现三处呈现口径需要固定：(a) `tab_attribution_response` 中"归因注册"对使用合并注册率的单元显示为 0（注册成本随之发散）——归因求和使用了非负最小二乘的原始估计 $\hat r_u$（被截断在 0 的单元）而非下游实际采用的注册率 $r_u$；(b) 校验表以"单个问题与凸松弛上界的最大相对差"（0.20）作为最优性证书，但该最大值来自一个预算仅 1.8 元（不足 20 倍最小投放额）的微小问题，松弛界在此处不具信息量；(c) 图 `fig_allocation_mix`（各类关键词消费占比：实际 vs 最优）在两个窗口均为"重点词 ≈ 99%"，不能说明最优分配把钱从哪些词移到哪些词。

## 备选方案
- (a) 保持原始估计口径 / 改为下游实际采用的 $r_u$（单元估计或合并回退）并同时保留原始值。
- (b) 只报告最大相对差 / 报告总体界 $(\sum \text{上界}-\sum \text{目标值})/\sum \text{目标值}$ 并分别给出"信息量充分的问题"上的最大相对差与微小问题的数目。
- (c) 保留占比图 / 改为"关键词最优窗口日均投放 vs 2025 年日均消费"的双对数散点（按类别着色，附 45° 线与上限线）与"候选 vs 至少入选一天"的类别计数。

## 决策与理由
采用每项的第二个方案。(a) 分类（MDR-0004）、分配（MDR-0006）与预测均使用回退后的 $r_u$，论文表格的口径应与之一致；原始 NNLS 估计仍写入 `attribution.json`（`attributed_regs_raw`）供审计。(b) 最优性证书的正确读法是总体界：所有单元-日问题目标值之和与凸松弛上界之和的相对差（`QthreeAggregateGapPct`）；单个微小问题的松弛界与带最小投放额的整数型选择问题相差可达数十个百分点，但对总目标的贡献可忽略，故单独列出而不作为证书。(c) 散点图直接展示分配机制：高效率词被推到上限（沿上限线），低效率词被剔除或压缩。

## 对结果的影响与验证
(a) 仅影响 `AttributedRegs`、`CostPerAttributedReg` 与该表；不改变任何模型输入。(b) 不改变审计结论（全部通过），只改变呈现。(c) 图文件由 `fig_allocation_mix` 改为 `fig_allocation_shift`。以上均在同一 run 内重跑 `eda` 起的全部科学阶段与门禁复现。
