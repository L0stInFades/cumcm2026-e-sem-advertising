# MDR-0006 预算定义、关键词入选规则与分配模型（问题三）

日期：2026-09-12 · 状态：已采纳 · 关联问题：问题 3

## 问题
"在保证各推广单元的低成本、高效益、完成但不超过预算资金的条件下，选择合适的关键词"——预算未给出，"关联关系"与"选择"的含义需要解释。

## 备选方案
- 预算：(a) 该单元当日 2025 年实际消费；(b) 该单元全年日均消费；(c) 8 天窗口内该单元消费总额，允许跨日调配。
- 目标：(i) 最大化预期点击；(ii) 最大化预期注册 $\sum_i \rho_i q_i(x_i)$；(iii) 最大化效益指数。
- 关联关系：(α) 同一关键词 ID 在多个单元重复投放时只保留效率（$\rho_i/\text{CPC}_i$）最高的一份；(β) 各份独立参与，关联关系体现为"词属于单元（预算结构）、同一单元共享弹性、类型决定上限"，重复 ID 作为问题一的发现在论文中提示合并。
- 类型使用：无效词不入选；问题词的日投放上限减半；黄金/重点/潜力词正常参与。
- 选择机制：投放额低于 0.5 元/日的词视为不投放并重解，保证入选词都有实际意义的投放额。

## 决策与理由
主方案 (a)+(ii)+(β)：预算等于实际消费使"最优策略 vs 实际做法"在同样的钱上可比；(α) 曾被尝试，但它把强词从某个单元中剔除，使"按历史比例"基线可以使用优化器不能使用的词，比较失去意义，故弃用。符号与论文正文统一：$\mu$ 为上限倍数（4.0），$m$ 为最小投放额（0.5 元）。上限取
$$\bar x_i=\max\{\mu\,\phi_i\,s_i,\ B_{u,d}\,s_i/\textstyle\sum_{j\in\mathcal K^{e}_u} s_j,\ m\},\qquad \bar x\leftarrow\bar x\cdot\max\{1,\ 1.2B_{u,d}/\textstyle\sum_i\bar x_i\},$$
即不低于历史比例份额（$\phi_i$ 为类型因子，问题词 0.5），并在必要时等比例放大以使预算可用完。模型（每个单元-日）：
$$\max_{x}\ \sum_{i\in\mathcal K^{e}_u} \hat\varepsilon_{u,d}\,\rho_i c_i (x_i/s_i)^{\gamma_u}\quad \text{s.t.}\ \sum_i x_i \le B_{u,d},\ x_i\in\{0\}\cup[m,\bar x_i].$$

**可行性论证的更正（v1.0.1）**：本 MDR 原先写"保证基线可行、最优值不低于基线"。这只对去掉最小投放额的凸松弛成立：含 $x_i\in\{0\}\cup[m,\bar x_i]$ 时，历史比例点的正坐标中有 87.5%（11,301 / 12,917）低于 $m$，基线并不在可行域内，故"最优值 ≥ 基线值"不能由可行性先验推出。现改为经验结论并逐一核对：107 个单元-日全部满足 opt ≥ prop，最小比值 1.0062（`allocate/baseline_feasibility.json`）。可分离严格凹目标 + 线性约束 ⇒ KKT 条件充要，解为注水形式 $x_i=\min\{\bar x_i,(\gamma a_i/\lambda)^{1/(1-\gamma)}\}$，$\lambda$ 由单调方程的二分法确定（全局最优）。(c) 作为备选：以日历回归得到的日效率乘子 $E[\varepsilon_{u,d}]$ 在 8 天内再优化预算的时间分布（两层分解只在日内上限与最小投放额都不起作用时精确；本数据上上限经常起作用，故为启发式，其联合间隙在问题四用可分离凹松弛上界给出）。

**覆盖所有单元 vs 同预算可比（v1.0.1）**：主口径 (a) 使 2 月窗口只覆盖 2 个单元（其余单元春节停投）。取舍是明确的：(a) 是"优越性论证"的前提（同样的钱才能比较），而题目又要求给出"每个推广单元"的策略。因此本文两者都给：`result3.xlsx` 用主口径 (a)，另以 (b) 全年日均口径给出 2 月窗口覆盖全部 12 个单元的完整逐日方案（`allocate/plan_feb_annual_avg.csv`），并在论文 §6.5 说明两者的预算口径差别。

## 对结果的影响与验证
独立校验器（与求解器分离）逐个问题检查可行性、KKT 驻点条件、随机配对转移不可改进、与 cvxpy/Clarabel 求得的目标值一致；小规模实例与网格穷举对照（tests）。优越性以"同预算下最优 vs 按历史比例 vs 均匀分配"的预期注册量提升表示，并给出 $\gamma$ 自助法 95% 区间。2 月窗口仅两个单元有实际消费（其余单元春节停投），结果如实报告。
