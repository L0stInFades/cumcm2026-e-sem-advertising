# SEM 广告投放策略（CUMCM 2026 E 题）

本仓库是 2026 年高教社杯全国大学生数学建模竞赛 E 题的完整研究工程：原始题目与附件、云端流水线、模型与求解程序、测试、论文源码与交付物。所有数据处理、计算、绘图、排版与打包均在 Modal 云端按固定镜像执行；本地只做文本编辑、Git 操作、任务提交、下载与散列校验。

## 内容

- `docs/ENGINEERING_STANDARD.md`：工程规范（阶段/清单/契约/门禁/发布）。
- `docs/MODELING_STANDARD.md`：建模与写作标准、审稿清单。
- `docs/problem_brief.md`：题目分析与建模路线。
- `docs/mdr/`：建模决策记录；`docs/adr/`：工程决策记录。
- `pipelines/e/`：本题的全部模型、求解与结果生成程序。
- `manuscript/`：论文源码；`releases/<tag>/`：论文 PDF、结果工作簿、支撑材料与 SHA-256 清单。

## 复现

```bash
python3 tools/cli.py provision
python3 tools/cli.py run ingest,validate --new-run
# 科学阶段见 docs/RUNBOOK.md 与 pipelines/e/stages.py
python3 tools/cli.py run lint,test,paper,qa,package,release
python3 tools/cli.py release --version <tag>
```

## 结果概要

- **问题一**：2025 年投放 142.59 万元、83.5 万次点击、CTR 3.70%、CPC 1.71 元；消费极度集中（前 10 个关键词占 58%，单元 9657930100 占 57%）；法定节假日日注册数下降约 74%（HC3 稳健回归，$p<10^{-20}$），周一与周日因主动减投分别下降约 54% 与 47%；注册归因回归留出期 $R^2\approx0.74$，合并注册率约 7.9 人/百次点击。
- **问题二**：熵权效益指数 + 自然断点阈值（成本 41.6 元/年、效益 0.27）：黄金词 40、重点词 271、潜力词 977、问题词 49、无效词 890；与中位数法/高斯混合法的一致率约 79%/93%；独立复核通过。
- **问题三**：可分离凹规划（幂函数响应，单元弹性 0.65–0.93）的两阶段精确求解；同预算下预期注册量较"按历史比例"提升 12.4%（2 月窗口）与 28.0%（8 月窗口），弹性自助 95% 区间 [11.7, 13.4] 与 [27.5, 28.6]；凸松弛总体最优性界 0.08%；107 个单元-日问题全部通过独立审计。
- **问题四**：2026-09-11–17 预算 2.35 万元（2025 同期），期望注册最大化与用期望乘子的确定性问题同解（确定性等价），两层分配后 500 个蒙特卡罗情景给出预期点击 1.75 万（10%–90%：1.35–2.20 万）、注册 1194（923–1495）、CPC 1.34 元（1.07–1.73）；日历回归区间在滚动回测中的 80% 覆盖率为 78%–87%；若按全年日均口径安排预算，预期注册约翻倍（2025 年 9 月效率最高的单元被停投）。
- **局限**：关键词只有年度汇总，响应曲线由单元弹性外推（校准 MAPE 约 33%）；长尾词以最小投放额入选属外推（占预算与注册的份额均很小，见论文）；注册归因为回归推断；2026 年的趋势无法从数据识别。

详见 `docs/RESULTS.md`（数值键名、表格与图文件）与 `docs/mdr/`（建模决策）。
