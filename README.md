# SEM 广告投放策略（CUMCM 2026 E 题）

本仓库是 2026 年高教社杯全国大学生数学建模竞赛 E 题的完整研究工程：原始题目与附件、云端流水线、模型与求解程序、测试、论文源码与交付物。所有数据处理、计算、绘图、排版与打包均在 Modal 云端按固定镜像执行；本地只做文本编辑、Git 操作、任务提交、下载与散列校验。

## 内容

- `docs/ENGINEERING_STANDARD.md`：工程规范（阶段/清单/契约/门禁/发布）。
- `docs/MODELING_STANDARD.md`：建模与写作标准、审稿清单。
- `docs/problem_brief.md`：题目分析与建模路线。
- `docs/mdr/`：建模决策记录；`docs/adr/`：工程决策记录。
- `pipelines/e/`：本题的全部模型、求解与结果生成程序。
- `manuscript/`：论文源码；`releases/<tag>/`：论文 PDF、结果工作簿、支撑材料与 SHA-256 清单。

## 复现

```bash
python3 tools/cli.py provision
python3 tools/cli.py run ingest,validate --new-run
# 科学阶段见 docs/RUNBOOK.md 与 pipelines/e/stages.py
python3 tools/cli.py run lint,test,paper,qa,package,release
python3 tools/cli.py release --version <tag>
```

## 结果概要

方法：四层模型（描述 → 分类 → 优化 → 预测）共用一套结构参数（单元注册率 $r_u$、点击–消费弹性 $\gamma_u$、日效率乘子 $\varepsilon_{u,t}$）。全部计算在同一次云端运行内完成，论文中每个数字都可追溯到该次运行的某个阶段产物。

- **问题一（描述）**：2025 年投放 142.59 万元、83.5 万次点击、CTR 3.70%、CPC 1.71 元；消费极度集中（前 10 个关键词占 58.4%，Gini 0.968，单元 9657930100 占 56.7%），40.0% 的关键词全年零消费，290 个关键词 ID 被 2–4 个单元共用（633 条记录）。法定节假日日注册数变化 −73.7%（HC3 稳健回归 $p\approx8\times10^{-22}$；Mann–Whitney $p\approx4.6\times10^{-14}$），控制当日消费后的需求侧效应 −24.6%，在对数尺度上占总跌幅的约 21%，其余来自主动减投。归因回归（非负最小二乘 + 日历项）留出期 $R^2\approx0.74$，合并注册率 7.95 人/百次点击。
- **问题二（分类）**：熵权复合效益指数 + 两类 Fisher–Jenks 自然断点（成本阈值 41.6 元/年、效益阈值 0.276）：黄金词 40、重点词 271、潜力词 977、问题词 49、无效词 890；与中位数法/高斯混合法/等权效益的标签一致率约 78%/94%/99%，独立校验器逐词重推标签通过。
- **问题三（优化）**：每个单元–日一个含最小投放额的可分离凹规划，两阶段拉格朗日–注水法求解（选择问题非凸，故为启发式）。同预算下预期注册较“按历史比例”提升 12.35%（2 月窗口）与 28.00%（8 月窗口），107 个单元–日全部满足最优 ≥ 基线（最小比值 1.0062）；凸松弛给出的总体最优性界 0.08%。另给出覆盖全部 12 个单元的 2 月窗口备选方案（全年日均预算口径）。
- **问题四（预测）**：2026-09-11–17，同期口径预算 2.35 万元。确定性等价命题使随机问题化归为确定性问题；两层分配的联合最优性由“7 日 × 关键词”可分离凹松弛界定。500 个蒙特卡罗情景给出预期点击 1.75 万（10%–90%：1.35–2.20 万）、注册 1194 人（923–1495）、点击加权 CPC 1.34 元（1.07–1.73）。结果文件为全部 12 个推广单元给出逐日策略（2 个同期零预算单元以零行显式给出）。按全年日均口径（预算高 16.4%、恢复 2 个停投单元）确定性预期注册 2327 人，据此建议不要沿用 2025 年 9 月的停投安排。
- **检验**：Q3 的 107 个、Q4 的 75 个分配问题全部通过与求解器分离的校验器（可行性、KKT、随机转移/剔除/插入、CVXPY 凸松弛上界）；灵敏度 14 种情形提升均为正，并有“名义松弛的最优值不得低于基准”的自动单调性门禁；滚动回测（12 起点 × 7 天 × 12 单元）同时评估仅含残差的区间（覆盖率约 78%–87%，接近名义 80%）与实际部署的加宽区间（约 87%–92%，偏保守）。
- **局限（择要）**：关键词只有年度汇总，响应曲线由单元弹性外推，校准 MAPE 约 33% 且偏差有符号（2 月 +12%、8 月 −31%）；单元–日层面的水平偏差经重标定检验不削弱结论，词间弹性异质无法检验。注册率 $r_u$ 由回归推断，12 个单元中 6 个的原始估计触非负边界，去掉月份项后最大摆动约 3.6 倍。跳出率质量因子 $\kappa_i$ 无法用数据验证（关闭后 8 月提升降至 26.9%）。跨单元重复投放的蚕食不可识别，其暴露上界为预期注册的 16.3%。问题四区间中的年际漂移项是一条不可检验的约定。主模型不做跨单元预算再分配（其反事实收益 4.0%–32.3% 仅作对照）。详见论文第 9.2 节与 `docs/REVIEW_RESPONSE.md`。

详见 `docs/RESULTS.md`（数值键名、表格与图文件）与 `docs/mdr/`（建模决策）。
