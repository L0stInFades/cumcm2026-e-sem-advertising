复现步骤：安装 Modal 客户端并登录后，在仓库根目录依次执行 \nolinkurl{python3 tools/cli.py provision}（验证云端工具链）、\nolinkurl{python3 tools/cli.py run ingest,validate --new-run}（接入与契约校验）、\nolinkurl{python3 tools/cli.py run eda,classify,allocate,forecast,results,figures,tables --size medium}（四个问题的科学阶段与结果、图表）、\nolinkurl{python3 tools/cli.py run lint,test,paper,qa,package,release}（门禁、论文、质检、打包与发布）。每个阶段目录下的 \nolinkurl{manifest.json} 记录输入输出散列、参数、依赖阶段的输出摘要与环境；\nolinkurl{events.jsonl} 为结构化日志；\nolinkurl{numbers.json} 为该阶段登记的论文数字。随机性只经 \nolinkurl{ctx.seed_everything} 派生（种子见 \nolinkurl{configs/default.toml}），同一代码与配置下的重跑得到相同的输出摘要。问题三与问题四的独立校验报告分别为 \nolinkurl{allocate/allocation_audit.json} 与 \nolinkurl{forecast/allocation_audit.json}，分类复核报告为 \nolinkurl{classify/classification_check.json}，回测明细为 \nolinkurl{forecast/backtest.csv}。
